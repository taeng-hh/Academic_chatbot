# 구현 변경 기록

이번 변경은 기존 모의고사 분석 서비스와 개선지시서의 구조를 유지하면서 자연어 조회 범위를 넓히는 작업입니다. 사용자의 요청에 따라 이번 변경 후 테스트, 앱 실행, API 호출, 별도의 검증 절차는 수행하지 않았습니다. 이전 `output/validation` 결과는 이번 변경의 검증 결과가 아닙니다.

## 유지한 기본 흐름

- 영어 문제 PDF·정답/배점 PDF·OMR Excel 업로드 → Python 채점 → 세션에 결과 보관.
- 평균·중앙값·모집단 표준편차·학생별 정오표·문항별 오답 통계와 Excel 출력.
- 일상 대화와 시험 자료 조회의 분리, 없는 정보의 확인 불가 안내, 비밀 정보 공개 제한.
- 사용자 지정 문항이나 오답 문항을 기준으로 신규 문제 생성.

## 확장한 동작

- `intent_router.py`: 복수 의도 스키마에 석차/석차 범위·공동순위/점수순서·상하위 방향·정렬·동점 처리 조건 추가. 명백한 순위 표현은 직접 조회하고 나머지는 구조화된 의미 해석으로 전달.
- `report_tools.py`: 실제 학생 점수로 공동석차와 서로 다른 점수 순서를 계산. 등수 필터·구간·정렬·상하위 인원·경계 동점자 선택을 Python으로 수행.
- `agent_graph.py`: 선택된 학생을 후속 작업과 대화 참조에 연결. 조건부 집단 통계, 학생 비교·오답/미응답/감점, 정렬된 문항 통계와 특정 순위의 문항 조회를 구성.
- `openai_service.py`: 모델은 조회 조건을 해석하고 문항을 설명·생성하는 역할. 학생 점수와 통계 수치는 Python 조회 결과로 응답. 난이도 요청을 생성 입력에 반영.
- 유사 문제 사전 생성 결과는 동일 기준 문항의 첫 일반 요청에만 재사용. 추가/다른/난이도 변경 요청은 새로 생성. 여러 문제를 생성하다 실패하면 완료된 결과는 보존.
- `excel_export.py`: 기존 세 시트와 함께 `학생별 석차 및 답안` 시트 제공. 학생별 석차·점수 순서·총점·정오답/미응답 수·감점·실제 제출 답안 포함.
- `pages/analysis.py`: 안내 예시를 순위·조건별 집계·학생 간 비교·후속 문제 생성 중심으로 변경.

## 순위의 의미

공동석차는 같은 점수면 같은 등수이며 다음 등수를 동점자 수만큼 건너뜁니다. 서로 다른 점수 순서는 점수 종류를 하나씩 셉니다. 예를 들어 공동 1등이 두 명이면 일반적인 2등은 없을 수 있지만, 두 번째로 높은 점수의 학생은 별도로 존재할 수 있습니다. 이름 순서로 임의의 동점자 한 명을 고르지 않습니다.

## 실행 조건과 제한

명백한 기본 조회는 API 없이 처리하며, 낯선 표현의 의미 해석·일상 대화·해설·새 문제 생성에는 `OPENAI_API_KEY`가 필요합니다. 모델은 `OPENAI_MODEL`로 설정합니다. 스캔 PDF의 OCR, 추출이 불완전한 문항, 제공되지 않은 듣기 대본 등 기존 입력 제한은 유지합니다. 모든 자연어 표현의 정확도나 실제 20초 응답 달성은 이번 변경에서 검증하지 않았습니다.
